# VUE 3D Canvas — Export Directory

This folder holds exported single-language ZIP archives generated by the individual export GitHub Action workflows:
- `export-rust.yml` -> `export/vue3d-backup-rust.zip`
- `export-python.yml` -> `export/vue3d-backup-python.zip`
- `export-c.yml` -> `export/vue3d-backup-c.zip`

## Export Features
- **Media Filtering**: Video files and heavy meshes are omitted; all icons (`*.ico`, `*.svg`, `favicon.png`, `signature.*`) are strictly preserved.
- **Documentation Preservation**: All program MD files, `HANDOFF.md`, `API.md`, and `README.md` are included.
- **Workflow Options**: In each export workflow, you can choose whether to download the artifact from GitHub Actions and/or mirror it into this repository folder.
